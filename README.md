# 멍뭉이 털을 찾아라

우기가 멍뭉이의 흰머리를 뽑아주는 10단계 브라우저 게임입니다.

- 흰머리를 뽑으면 +5점, 검은 머리를 뽑으면 -1점, 제한 시간 안에 20점이면 통과
- 1단계는 맨손(2분), 단계마다 새 도구(족집게, 돋보기, 빗, 헤어핀, 헤드랜턴, 전동 족집게, 모래시계, 레이더, 황금 족집게)가 생기고 난이도가 올라갑니다
- 통과하면 멍뭉이가 춤추며 집에 가고, 다음 날 다시 우기네 집에 옵니다

- 멍뭉이와 우기는 3D 캐릭터예요. 걷고, 앉고, 춤추고, 눈을 깜빡이고, 말할 때 입이 움직이고, 표정(빵긋/찌릿)이 바뀝니다.
- 장면: 우기네 집(벽난로, 소파, 책장, 고양이), 호수가 있는 멍뭉이네 가는 길, 멍뭉이 방(다음 날 아침).
- 도구는 3D로 나타나요. 우기 손 → 족집게 → 전동 족집게 → 황금 족집게로 직접 집어서 뽑고, 빗·모래시계·레이더는 누르면 나와서 움직여요. 헤어핀과 헤드랜턴은 머리 옆에 보여요.
- 멍뭉이는 단계마다 다른 방법(춤, 토끼뜀, 스킵, 빙글빙글, 비행기, 행진, 문워크, 꽃게걸음, 달리기, 만세 점프)으로 집에 가요.
- 다음 날 아침에는 멍뭉이가 혼자 일어나 "우기 집으로 가볼까?" 하고, 「우기 집으로 가기」를 누르면 스스로 걸어 나가요.
- 게임 화면에서는 끌어서 멍뭉이 머리를 돌려 볼 수 있어요. 흰머리가 뒤통수에 숨어 있을 수도 있어요. 톡 누르면 뽑습니다.

## 실행

`index.html`과 `vendor/three.module.min.js`(3D 엔진 Three.js r160, MIT 라이선스)로 동작하는 정적 사이트입니다. 3D 엔진이 모듈 파일이라 파일을 더블클릭해서 열면 안 되고, 웹 서버로 열어야 합니다 (예: `python3 -m http.server` 후 http://localhost:8000). Vercel 같은 정적 호스팅에는 그대로 올리면 됩니다.

## 테스트

```
npm install
npx playwright install chromium
npm test
```

테스트는 `vercel.json`의 보안 헤더를 붙여 로컬 서버로 페이지를 띄우고, 3D 장면이 그려지는지, 시작 흐름, 점수, 통과/실패, 단계별 도구, 다음 날 진행, 엔딩, 머리 돌리기, 모바일 터치를 확인합니다.

배포된 사이트를 테스트하려면 주소를 넣어 실행합니다.

```
GAME_URL=https://game-steel-five-44.vercel.app npm test
```
